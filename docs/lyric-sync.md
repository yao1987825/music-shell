# 歌词与播放进度同步

music-shell 使用带时间戳的 LRC 歌词，并根据播放器当前播放位置选择高亮行。歌词时间戳按歌曲开始后的时间计算；例如 `[00:12.34]` 表示播放到 12.34 秒时切换到该行。支持一行包含多个时间标签。

```text
[00:12.34]窗外的麻雀
[00:15.60]在电线杆上摇摇晃晃
```

## 同步与刷新

- 当前歌词行根据播放器的播放时钟确定，而不是根据已经经过的墙上时间或上一行的顺序推进。
- 暂停时播放器位置冻结，因此歌词高亮也保持不动；继续播放后再随位置推进。
- 主循环每约 200 毫秒刷新一次界面。播放位置由音频后端提供，并通过播放器时钟校准；静音模式使用逻辑播放时钟。
- 渲染器会分别检测歌词区域与播放状态行的变化。两者同时变化时会在同一帧更新，状态行定位也会计入歌词面板占用的行数，避免状态刷新覆盖歌词高亮。
- 歌词面板显示当前行附近的上下文；`lyric_panel_lines` 控制显示行数，设置为 `0` 时隐藏面板。

## 歌词来源

按优先级读取：音频文件旁的同名 `.lrc` / `.txt`、配置的 `lyrics_dir` 中的同名文件、音频文件内嵌歌词。歌词文件需要包含时间戳；不带时间戳的纯文本行不会参与同步高亮。

```json
{
  "lyrics_dir": "/home/you/Music/.lyrics",
  "lyric_panel_lines": 5
}
```

歌词高亮以 LRC 时间戳为准。如果歌词文件时间与音频内容本身不一致，显示也会相应提前或延后；请使用与音频版本匹配的 LRC 文件。
